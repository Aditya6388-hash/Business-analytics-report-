# Business Analytics Report

## 📊 Overview
This project presents a complete Business Analytics solution using sales data. The project includes data cleaning, data analysis, KPI calculation, forecasting, and an interactive dashboard to support data-driven business decisions.

## 🎯 Objectives
- Clean and prepare raw business data
- Remove duplicate and incorrect records
- Handle missing values and formatting issues
- Calculate important business KPIs
- Analyze sales and business trends
- Perform historical forecasting
- Create an interactive business dashboard
- Generate a professional business analysis report

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Dashboard
- Power BI
- Tableau
- CSV
- Data Analysis & Visualization

## 📁 Project Files
- `analysis_workbook.xlsx` – Data analysis and Excel workbook
- `business_analysis_report_20_pages.pdf` – Detailed business analysis report
- `cleaned_orders.csv` – Cleaned dataset
- `dashboard.html` – Interactive dashboard
- `historical_forecast_baseline.csv` – Forecasting data
- `kpis.csv` – Key Performance Indicators

## 📈 Key Analysis
The project focuses on:
- Sales Performance
- Revenue Trends
- Customer Analysis

- Historical Trends

## 💡 Business Insights
The analysis helps identify sales trends, high-performing areas, business bottlenecks, and potential growth opportunities. The dashboard provides a quick overview of important metrics for faster decision-making.
